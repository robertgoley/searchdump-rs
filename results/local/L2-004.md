# L2-004: 1.2-1d `--serverLimits=off|auto|min|check` in `searchdump` (probe, budget, fallbacks)

Owner request t196u (2026-11-15), phase 1.2-1d of `project/plan/ROADMAP-1.2-PLAN.md` sections 2, 3, 7
and 8.2-8.3. Builds on L2-003 (429 halving/splitting, in force in every mode).

## What

- New module `src/limits.rs`: `Mode` (`off|auto|min|check`, `DEFAULT_MODE = Auto`, PROVISIONAL Q1),
  `probe()` (read-only: `GET _nodes/stats/jvm,breaker[,indexing_pressure]` with `filter_path`, retried
  without `indexing_pressure` on an old version's 400; `GET _nodes/settings` for
  `http.max_content_length` (100mb when not set; `include_defaults` is rejected by the nodes info API
  on ES 7.10-9.1, found by the fixture capture, plan section 3 corrected); `_cat/thread_pool` for the
  multi parent), one deadline `PROBE_DEADLINE` = 5 s for the whole probe.
- Budget (section 3.1) from the **smallest data node**: page = 25 % (`auto`) / 12.5 % (`min`,
  PROVISIONAL Q2) of min(parent-breaker free, request breaker), never above the 256 MB response cap;
  in flight 50 % / 25 % of parent free; bulk total 50 % / 25 % of min(indexing pressure, parent free);
  bulk cap = `http.max_content_length` - 1 MB, or 10 MiB on AWS hosts (`AWS_PAYLOAD_FLOOR`,
  PROVISIONAL Q5). Page documents = clamp(page bytes / (avg stored bytes x `EXPANSION` 3), 1, max).
- `searchdump` (single index) under `auto`/`min` only **tightens** its own defaults (`--limit=100`,
  100 MB bulks); explicit `--limit` / `--maxBulkBytes` / `--maxResponseMb` win with a warning when
  above the limit; `check` prints the limits and sizes and exits 0 before any data request, or 2
  when an explicit value is over the limit; `off` sends no probe (1.1.0 behaviour exactly).
- Fallbacks never fail a run: 403 (no `monitor` privilege), 404/410/400 (serverless, proxies),
  missing heap/breaker fields, AWS OpenSearch Service hosts (`*.es.amazonaws.com`, `*.aos.*.on.aws`:
  10 MiB bulk floor), serverless hosts, probe over the deadline -> one
  `server limits: unknown (...) -> fixed 1.1 defaults [mode]` line.
- One `server limits:` line on stderr (section 7); `--statsFile` gains a `server_limits` object.
- `tests/golden/endpoints.toml` E22 (the probe endpoints are read-only GETs); RouterMock answers the
  probe outside the routes unless a test opts in (`serve_probes`), so existing request-sequence tests
  are unchanged.
