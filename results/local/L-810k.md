# L-810k: examples/ updated for the changes on main after 1.0.0

Owner go-ahead 2026-11-14 (t95u): update `examples/` for today's changes. Only behaviour that is on
`main` is described; the 1.1-10 defaults are on `release/1.1` only, so the examples keep the
explicit small-heap overrides and only point to 1.1.

## Changes

- **Exit status 4** (L-804b): new "Exit status and reruns" table in `examples/README.md`;
  `rerun_on_4` in `bash/_common.sh` and `docker-podman/_common.sh` (rerun on exit 4 only,
  `RERUNS` default 1, `RERUN_DELAY` default 30 s) wraps every `searchdump` run of the dump and
  cluster-copy scripts; `kubernetes/very-large-index-dump.yaml` gets a `podFailurePolicy` that
  retries only exit 4 (`backoffLimit: 2`) and fails the Job at once otherwise.
- **`--httpAuthFile` wins** (L-645b): README credential, TLS and cluster-copy text corrected (the old
  text suggested `--httpAuthFile` with `--input-username`/`--output-username` when users differ,
  which no longer works); `warn_auth_file_wins` prints a note in both copy scripts when
  `HTTP_AUTH_FILE` and `SEARCHDUMP_*_USERNAME` are both set; k8s copy Job comment.
- **`--restartOnContextLoss`** (L-804b): opt-in `RESTART_ON_CONTEXT_LOSS=N` in the very-large-index
  dump (bash, Docker/Podman, Kubernetes), off by default because 1.0.0 binaries and the published
  1.0.0 images reject the flag.
- **SFTP in images** (L-810i/L-810j): README says the published 1.0.0 images have no `ssh`, while
  images built from `main` (`make image*`, not dhi-static) include the OpenSSH client; key and
  `known_hosts` notes.
- **Small-heap `searchdump-multi`** (1.1-10 analysis): the warning now cites the 2026-11-14
  reproduction (256 MB-heap ES 7.10.2/8.6.1 OutOfMemoryError, 8.19.23 HTTP 429); new advice and
  `MAX_BULK_BYTES` (default `16mb`) in the multi-index restore scripts and Job, because 5000-document
  100 MB bulks were refused by `indexing_pressure` even at a 1 GB heap.
- **Corrections:** "compression defaults to zstd level 1" was wrong (gzip is the default codec, zstd's
  default level is 3; the examples pass `--compressionLevel=1`). **7 of 14 Kubernetes manifests were
  invalid** (numeric `env` values such as `value: 1000`; Kubernetes requires strings): all quoted.
