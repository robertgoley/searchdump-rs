Owner request t109u / t196u (2026-11-15), phase 1.2-1h of `project/plan/ROADMAP-1.2-PLAN.md` section 12.
Docs and scripts only; no product code. Builds on L2-004 (`--serverLimits` in `searchdump`) and L2-005
(`searchdump-multi`).

## What changed

- **New safe-simple cases** (no `--limit`, `--maxBulkBytes`, `--maxResponseMb`, `--parallel`, `--slices`;
  `--serverLimits=${SERVER_LIMITS:-auto}` written out so it is visible):
  - `examples/bash/safe-simple-{dump,restore,multi-dump,multi-restore}.sh` and `examples/bash/_preflight.sh`;
  - `examples/docker-podman/safe-simple-*.sh` (same four through `run_image`) and `examples/docker-podman/_preflight.sh`;
  - `examples/kubernetes/safe-simple-{dump,restore,multi-dump,multi-restore}.yaml` (Job with a
    `--serverLimits=check` init container; credentials only from a Secret as blank env references).
  - Preflight (12.3): run the command with `--serverLimits=check`, branch on the exit code only (0 go,
    2 stop before any data moves, other = preflight failed); the printed `server limits:` line is never parsed.
- **Existing cases**: the hand-tuned small-heap overrides (`-- --limit=500 --maxResponseMb=64`,
  `MAX_BULK_BYTES=16mb`, `--parallel=1`) in `minimum-resources-*` and `multi-index-*` are replaced by
  `--serverLimits=min` / `auto`, with a commented manual-override block; `fastest-*`, `very-large-index-*`,
  `object-storage-*`, `secure-tls-auth-*`, `cluster-to-cluster-copy` add `--serverLimits=auto` and the
  1.2.0 image tag.
- **`examples/README.md`**: new first section "Safe simple (recommended)" (the four cases in three forms,
  the preflight, the fallback table of 12.4, "when to override" of 12.5); exit-code table notes `check`'s 2.
- **`README.md`**: "Quick usage" leads with the safe-simple recipe (one `check`, one dump, one restore);
  the `searchdump-multi` data-defaults paragraph describes the 1.2 sizing (`off` = 1.1 sizes); new section
  "Server limits (`--serverLimits`)" (what is probed, the auto/min table, check, fallbacks, AWS 10 MiB,
  provisional section 9 answers, automax design-only pointer).
