# L2-006: 1.2-1f lowheap acceptance with `--serverLimits` (auto / off / 1.1.0 / min) on ES and OpenSearch

Owner request t196u (2026-11-15), phase 1.2-1f of `project/plan/ROADMAP-1.2-PLAN.md` (section 8 item 4,
section 6 docs). Builds on L2-005. Script and docs only; the binaries are the frozen 1.2 candidate built from
L2-005 (`/workspace/perf-1.2/bin-1.2rc`; the 1.1.0 row uses `/workspace/perf-1.2/bin-1.1.0` with `--mode none`).

## What changed

- `scripts/load/lowheap.py`: `--mode auto|off|min|none` (default `auto`) adds `--serverLimits=MODE` to every
  `searchdump-multi` dump and load (`none` for a 1.1.x build); the OpenSearch cells `os13` (1.3.20), `os2`, `os3`
  (pinned `opensearch:2` / `:3`); the JSON records each dump's `server limits:` line and the mode.
- `scripts/load/README.md`: the new options, the OpenSearch cells and the 256m OpenSearch floor (Q7, provisional),
  the companions `limits_fixtures.py` and `workerpage.py`.
- `examples/README.md` "Minimum resources": the 1.2 lowheap result.

## Runs (box, isolated podman store, port 19256; 7 engines x 256m/384m, datasets pmc 20,000 x ~22 KB and fat 3,000 x ~78 KB)

Commands (`/workspace/perf-1.2/chain-1f.sh`): `lowheap.py --engines es710,es861,es819,es912,os13,os2,os3 --heaps 256m,384m`
with `--mode auto --regression`, `--mode off`, `--mode none` (1.1.0 binaries) and `--mode min`. Raw:
`results/local/L2-006-{auto,off,v110,min}-lowheap.json` (copies of the gitignored `results/load/L2-006-*/lowheap.json`); logs `/workspace/logs12/lowheap-L2-006-*.log`.
Per cell: dump/load wall for pmc then fat (dump-pmc/load-pmc/dump-fat/load-fat), HTTP 429 lines over all the
cell's steps (seeding included), and the `pmc` page the multi parent chose.

## Notes

- OpenSearch 1.3, 2 and 3 all boot and pass at 256m, so 256m stays the OpenSearch floor of the acceptance set
  (ROADMAP-1.2 Q7, provisional answer).
- OpenSearch 3.9.0 at 384m: `auto` load-fat took 104.9 s (0 HTTP 429 in that step, digest equal, node alive)
  against 3-5 s on the other cells; seeding the same node also logged parent-breaker 429s. Compare the off/min rows;
  recorded for 1.2-1g follow-up.
- Wall-time outliers outside auto: v110 es819/384m dump-fat 3350 s, v110 os13/256m load-pmc 6681.9 s, min es710/384m load-fat 4856.8 s, min es912/384m dump-fat 342.8 s. All passed (digests equal, node alive); these look like stalls (box contention or a paused step), not engine behaviour, and were not re-run.
- Gates: `python3 -m py_compile scripts/load/lowheap.py`, gitleaks history and tree scans of `scripts/sup/secret-scan.sh` clean (its cargo canary step was not run: default toolchain on the box is older than rustc 1.91).
