# L2-003: 1.2-1c HTTP 429 page halving and bulk splitting in `searchdump`

Owner request t196u (2026-11-15), phase 1.2-1c of `project/plan/ROADMAP-1.2-PLAN.md` section 5 (the
deferred 1.1 item). Independent of `--serverLimits` (which does not exist yet at this commit): it
applies with the 1.1.0 sizing, so it is in force under `--serverLimits=off` later too.

## Behaviour

| Request | HTTP 429 type | 1.1.0 | 1.2 (this commit) |
|---|---|---|---|
| Initial scroll search, PIT / `search_after` pages | `circuit_breaking_exception` (page did not fit the heap) | same page re-sent until `--retryAttempts` run out, then exit 4 | page halved (sent without 429 retries so the breaker answer comes back at once), jittered first-retry delay (0.5-1.5 x `--retryDelay`), sent again; the smaller size stays for the rest of the slice (never grows back). One warning per halving. Floor 1 document; at 1 document the normal retry policy applies and a final 429 still exits 4 (rerun-safe). |
| Scroll continuation (`_search/scroll`) | any | plain retry | unchanged: a scroll's size is fixed by its initial search, so continuations keep the plain retry (the initial-search halving already sized it). |
| Search pages | other 429 (full search queue) | retry | unchanged retry, same size (a smaller page waits in the same queue). |
| `_bulk` request of 2+ documents | `circuit_breaking_exception`, or `es_rejected_execution_exception` naming indexing pressure / memory bytes | whole bulk re-sent until retries run out | split in half; halves written in input order, recursively down to 1 document; nothing of a refused request was applied, so only unacknowledged documents are sent (no duplicate writes). The run's bulk byte cap drops to the size that fit (shared by workers, never grows back). |
| `_bulk` | `es_rejected_execution_exception` for a full write queue (no memory limit named) | retry | unchanged retry, same body. |
| Item-level 429/503 inside a 200 bulk answer | - | only those items re-sent | unchanged. |
| `--retryAttempts=0` or `--retryOn` without 429 | - | no retry | no halving or splitting either (they are retries). |

Code: `src/http/retry.rs` (`is_size_429`, `is_http_429`, `RetryPolicy::retries_429/without_429/
jittered_first_delay`), `src/retrieval/retrieval_task.rs` (`send_page_halving`), `scroll.rs`,
`search_after.rs`, `pit_search.rs` (initial / page requests through it), `src/pipeline/bulk.rs`
(split on a whole-request size 429, shared lowered cap).
